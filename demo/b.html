简历优化建议

针对 AI应用研发工程师 · 3 条改法

怎么补这几项

01

LangChain

为什么你的项目里没有编排层，JD 要求能独立搭链路。

怎么做把现有 Flask 接口串成一条链，先做最朴素的 RetrievalQA，跑通再谈优化。

chain = RetrievalQA.from_chain_type(llm, retriever=vectorstore.as_retriever())
02

RAG

为什么JD 把检索链路写进了硬性要求，你还没有可讲的实现。

怎么做拿你清洗过的岗位数据做语料，先跑通切分、召回、拼上下文三步。

retriever = vectorstore.as_retriever(search_kwargs={"k":4})
03

Prompt 工程

为什么你写过需求文档，但提示词还没当成一份可迭代的交付物。

怎么做给每条提示词留版本号，用 20 条固定问题记录改前改后的通过率。

prompt = f"{SYS}\n\n用户：{q}"

句子改写

原文

使用 Python 完成数据清洗与分析

改后

用 Python + Pandas 清洗 3 万条岗位数据，产出 12 个细分方向的技能热度表

原文

熟悉 Spring Boot 与 MySQL，参与过后台接口开发

改后

用 Spring Boot + MyBatis 做过后台接口，能独立定位 MySQL 慢查询
